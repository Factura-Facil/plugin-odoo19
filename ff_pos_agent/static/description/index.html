Factura electrónica DGI Panamá en el Punto de Venta

Odoo 18 POS con Factura Fácil: por el Agente Offline de la tienda o por su API en línea

Cada venta que se cobra en la caja se firma, se envía a la DGI y vuelve con CUFE y QR oficial, que se imprimen en el recibo como CAFE. El cajero no hace nada distinto, y una caída del agente nunca bloquea la venta.

Qué resuelve

  • Timbrado automático al validar el pago, y el CAFE en el recibo con los 13 elementos exigidos por la DGI.
  • Notas de crédito: las devoluciones se emiten como NTC referenciando la factura original.
  • Clientes con RUC: validación contra la DGI desde la ficha del cliente, sin salir del POS.
  • Facturas a Gobierno con código CPBS (GNS) por artículo.
  • Descuentos globales, premios y precios con ITBMS incluido: lo emitido cuadra con lo cobrado.
  • Sin facturas duplicadas: nunca reenvía una venta que el agente pudo haber recibido.
  • Tolerante a fallos: si el agente no responde, la venta queda pendiente y se emite sola.
  • Monitor de facturas por estado (pendiente, incierta, timbrada, autorizada, rechazada).
  • Auditoría completa: el payload enviado y la respuesta del agente quedan en cada orden.
  • Formas de pago y unidades DGI configurables, incluidas las ventas a crédito.
  • Dos modos: Agente Offline (emite sin internet) o API en línea (autoriza al momento y adjunta el PDF oficial del CAFE).

Configuración en minutos

  1. Instala el módulo y, en los ajustes del POS, activa Agente Factura Fácil.
  2. Carga la URL del agente, el Company UUID y la API Key que te da Factura Fácil.
  3. Pulsa Probar conexión: la prueba se hace desde el servidor de Odoo, que es quien habla con el agente.
  4. Revisa la forma de pago DGI de cada método de pago.

Seguridad

  • La API Key y el Company UUID solo los ve un responsable del POS y nunca se cargan en el navegador de la caja.
  • El estado fiscal no se puede editar a mano: lo escribe únicamente el flujo de emisión.
  • La auditoría enmascara la API Key: se puede compartir con soporte.

Requisitos

  • Odoo 18 con Punto de Venta.
  • Agente Offline de Factura Fácil instalado y sincronizado, alcanzable desde el servidor de Odoo.
  • Credenciales de Factura Fácil (Company UUID y API Key).
  • Opcional: la librería Python qrcode para imprimir la imagen del QR en el recibo.
